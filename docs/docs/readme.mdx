# Opsmill.Infrahub

Collection version 1.3.0

## Description

Infrahub modules for Ansible using Ansible Collections

**Supported ansible-core versions:** >=2.15.0

## Plugin Index

These are the plugins in the opsmill.infrahub collection:

### Modules

- [query_graphql](plugins/query_graphql_module) – Queries and returns elements from Infrahub GraphQL API- [artifact_fetch](plugins/artifact_fetch_module) – Fetch the content of an artifact from Infrahub
### Inventory Plugins

- [inventory](plugins/inventory_inventory) – Infrahub inventory source (using GraphQL)
### Lookup Plugins

- [lookup](plugins/lookup_lookup) – Queries and returns elements from Infrahub (using GraphQL)
## Role Index

These are the roles in the opsmill.infrahub collection:
- [install](roles/install) – Install Infrahub
