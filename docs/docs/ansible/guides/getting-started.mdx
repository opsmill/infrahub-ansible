## Ansible galaxy

Run the following command to install the `opsmill.infrahub` collection:

```console
ansible-galaxy collection install opsmill.infrahub
```

:::info

Installing Ansible Collections using Git within a requirements.yml is not supported until Ansible 2.10.

:::

Follow the [official docs](https://docs.ansible.com/ansible/latest/user_guide/collections_using.html) to learn more about other installation methods.

## Build

<Tabs>
<TabItem value="Build From Source" default>

Follow these steps to install from source:

```console
git clone git@github.com:opsmill/infrahub-ansible.git
cd ansible_modules
ansible-galaxy collection build .
ansible-galaxy collection install opsmill-infrahub*.tar.gz
```

</TabItem>
<TabItem value="Build From Source (Pull Request)">

This is useful to test code within PRs.

```console
git clone git@github.com:opsmill/infrahub-ansible.git
cd ansible_modules
git fetch origin pull/<pr #>/head:
git checkout
ansible-galaxy collection build .
ansible-galaxy collection install opsmill-infrahub*.tar.gz
```

</TabItem>
</Tabs>

:::info

:::
